## The entry

`main.py` writes one sentence to `/output/entry.txt` — a startup pitch
so strange it sounds like a joke, yet specific enough to see the
customers and the money:

> We turn strangers' spare attics into phone-free nap pods, charging burnt-out remote workers $20 an hour to hide from meetings, calendars, and their own Slack.

The odd thing being sold is a stranger's attic as a nap pod; the paying
customers are burnt-out remote workers at $20 an hour; and the business
logic holds because silence is the product — every remote worker already
knows the feeling of needing exactly that hiding place.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
